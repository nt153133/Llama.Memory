## 2024-05-22 - [Single-Pass Pattern Frequency Loop]
**Learning:** Optimizing dual-pass span traversals in the `PatternSearcher.GetFrequencyTables()` method down to a single-pass traversal yielded a measurable performance improvement (~9% reduction in execution time). Consolidating loops that compute character/byte frequencies alongside sequential pair frequencies over large inputs is highly effective here because it significantly reduces array bounds checks and memory reads.
**Action:** When calculating statistics over arrays/spans in this codebase (especially large data chunks, such as PE memory footprints), look for opportunities to compute contiguous sub-elements (like byte-pairs or n-grams) in the same pass as individual element frequencies to avoid redundant iterations.
